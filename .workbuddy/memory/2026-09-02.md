## 第三方库调研（docs/thirdparty.md）

数据来源：crates.io API / docs.rs / HuggingFace API 实测（2026-09-02），Rust stable 1.98.0。

**引入**：jieba-rs 0.10.3、unicode-segmentation、unicode-normalization、fastembed 6.0.2、instant-distance 0.6.1、moka（替换 lru，并发安全+TTL）、bincode 3.0.0、crc32fast、工程基础件、cargo-deny（License 合规）。

**关键发现**
1. **tantivy 作 dev-dependency 当 oracle**（MIT）：不用它实现功能，用它验证手写 BM25 正确性 + P5 第三基线。自研最大风险是"写错了看不出来"。
2. **hnsw_rs 0.3.4（MIT/Apache-2.0，纯 Rust）支持增量 insert + search_filter + DistDot（明确要求入库前 L2 归一化，与我们的方案天然契合）** → R1 风险可能从"绕开"变成"消除"，P4 做 A/B，达标则删掉 delta 区设计（T4-06）。无 remove，但墓碑删除不依赖物理删除，不构成问题。
3. **MSRV 冲突（必改）**：NFR-08 定 1.80，但 bincode3=1.85、clap=1.85、smol_str=1.89、criterion=1.86、roaring=1.90；当前 stable 1.98。建议 MSRV → 1.90。
4. **架构文档 7.6 事实错误**：instant-distance 的 with-serde 只引 serde + serde-big-array，**不含 bincode**；bincode 版本可自由选。
5. 版本过时：fastembed 5.17.4→6.0.2（两者都 pin `ort =2.0.0-rc.13` 预发布，无法规避）、arroy 0.5.0→0.8.0。
6. 非 crate 许可：ONNX Runtime 二进制 MIT；bge-small-zh-v1.5 / bge-m3 = MIT；bge-reranker-v2-m3 = Apache-2.0。

**排除**：arroy（耦合 LMDB，与内存+快照冲突）、redb/sled/heed、dashmap（7.x 仍 rc）、charabia（默认 feature 太重，P5 用裁剪版做分词对照）、lindera、stop-words（自维护词表）、text-splitter（v2）、axum（不做服务层）。
